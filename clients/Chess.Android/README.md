# Android client

The client uses a .NET for Android `Activity` with native Android views. It targets Android API 37 and supports Android API 24 and newer. Install the Android workload matching the SDK in `global.json`, the Android SDK, and a supported JDK.

For a Linux development machine with the Android SDK under `/opt/android-sdk` and JDK17:

```sh
dotnet build clients/Chess.Android -r android-x64 \
  -p:AndroidSdkDirectory=/opt/android-sdk \
  -p:JavaSdkDirectory=/usr/lib/jvm/java-17-openjdk
adb install -r clients/Chess.Android/bin/Debug/net11.0-android37.0/android-x64/org.shirubasoft.chess-Signed.apk
```

Use `-r android-arm64` when producing an APK for ARM64 devices. Release packages remain untrimmed because the shared core's JSON converter discovers union cases through reflection. Release builds omit standalone PDB files, which avoids missing symbol-path metadata in the preview Android SDK's untrimmed packaging target. Debug packages include their managed assemblies so installation through `adb` produces a standalone runnable app.

The Android emulator's default server is `http://10.0.2.2:5080/`. Physical devices need a server address reachable from their network. The server field accepts HTTP or HTTPS, and the manifest allows HTTP for local development. Deploy public servers with HTTPS.

Create a game or choose Find opponent. Game & connection exposes the server, joining controls, and side codes while a game is open. Share the opponent code and keep your own code. Join / resume accepts a side code generated by any client. The own code and server address are saved in private application storage, with Android backups disabled. The app refreshes on returning to the foreground and polls every three seconds while visible.

Resource IDs such as `square_e2`, `move_notation`, and `join_game` are stable for Android UI automation. The verification launch runs view clicks and routed touch gestures against a running test server and writes private `files/verification.json`:

```sh
adb shell am start -n org.shirubasoft.chess/org.shirubasoft.chess.MainActivity \
  --es server http://10.0.2.2:5080/ --ez verify_ui true
adb shell run-as org.shirubasoft.chess cat files/verification.json
```

The activity has an explicit stable name. The verification uses a separate private settings file. Its shared scenario is in `tests/Chess.Native.Tests`.

Drag one of your movable pieces to a legal destination, or select the source and destination with taps. The moving piece follows the pointer while its source and legal destinations remain marked. Releasing outside the board, a canceled touch or lost window focus, or a changed game position cancels the drag. Dragging a pawn onto its final rank opens the promotion choices. SAN and UCI entry remain available.
